# Презентации

- **[Текущая презентация, 5 слайдов](main.pdf)** — [LaTeX](main.tex).
- **[Прежний однослайдовый вариант](one_slide.pdf)** — [LaTeX](one_slide.tex).

`one_slide.pdf` и `one_slide.tex` — прежние GitHub-файлы `main.pdf` и `main.tex`, сохранённые без изменения содержимого под новыми именами.

Новая презентация перенесена из согласованной папки текущих материалов. Пятый слайд — сокращённый авторский текст о трёх условиях, без дополнительных подписей «теория/практика». Это авторская формулировка; её наличие не добавляет новых доказательств к статье.

Сборка только текущей презентации из корня репозитория:

```bash
python3 code/build_documents.py --target slides
```

Однослайдовый архив по умолчанию не пересобирается, чтобы сохранить исходный PDF побайтово.
