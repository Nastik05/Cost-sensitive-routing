# Численная устойчивость bootstrap

После завершения основной заранее заданной семьи1698контрастов с2000повторами обнаружены8gain-onlyвзаимодействий при accuracy-настройке. Один из интервалов почти касается нуля (Direct−Joint на TF10→TFfull); другие также близки к границе.

Для проверки Monte-Carlo устойчивости выполняется **один дополнительный расчёт10000повторов** с новым фиксированнымseed2026111214. Сохраняются все1698контрастов, те же данные, модели, выборы поdev, квота, формулы и правило общейmax-tпоправки. Никакие сравнения не добавляются/исключаются. Это не новая независимая репликация и не поиск иной семьи значимости.

Основные результаты2000повторов остаются в `statistics/`. Численный контроль записывается в `statistics_mc10000/`; публикуются все изменения знака интервала или статуса значимости, если они есть. Третьего расчёта ради желаемого результата не планируется.
