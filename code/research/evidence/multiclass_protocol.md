# Многоклассовые метрики замещающего каскада

## Цель

Посчитать precision, recall и F1 **по исходным классам итогового ответа**, а не по событиям rescue/harm. Используются уже обученные эксперты и замороженные решения роутеров BANKING77 и CLINC150. Обучение и выбор параметров не повторяются. Это дополнительный post-hoc анализ прежних тестов, не новая независимая проверка.

Все новые материалы находятся в этой папке. Старые статьи, презентации, данные, модели и GitHub сохраняются без изменений.

## Восстановление предсказаний

Для каждого запроса берётся argmax вероятностей первого эксперта; при эскалации он заменяется argmax второго. Квота, score, tie-breaking и выбранные на dev параметры строго совпадают с сохранёнными экспериментами. Правильность восстановленных меток сверяется с W/S из score-архивов, accuracy каждого каскада — с прежней таблицей.

- BANKING77: весь `submission_hw6/code/results/imbalance_all`, 21 пара, 20 seeds, 3 fit-объёма, 11 вариантов состава/коррекции, квоты10/20/40%, official/clean.
- CLINC150: весь `research_clinc_20261112/results`, 6 пар, 20 seeds, 2 fit-объёма, 3 состава, MSE/accuracy-настройка, три квоты, official/clean.
- Все обучаемые методы, имеющиеся confidence/random контроли и dev-selector включаются в описательные таблицы. Набор кандидатных моделей не меняется по новым метрикам.

## Определения

Для каждого класса c сохраняются TP, FP, FN, support и число предсказаний этого класса. Precision=TP/(TP+FP), recall=TP/(TP+FN), F1=2TP/(2TP+FP+FN). При нулевом знаменателе используется0, как `sklearn(..., zero_division=0)`; в усреднение входят все известные классы датасета.

- Macro — арифметическое среднее **метрик классов**; macro-F1 не вычисляется как гармоническое среднего precision и среднего recall.
- Weighted — среднее с весами истинных support классов.
- Micro — объединение всех классов перед вычислением метрики.

Контрольные тождества для single-label классификации без отказа: micro-P=micro-R=micro-F1=accuracy; weighted-recall=accuracy. Если test имеет одинаковый support всех классов, дополнительно macro-recall=accuracy, macro-P=weighted-P, macro-F1=weighted-F1. Баланс проверяется по фактическим меткам, а не предполагается.

Даже замена одного неправильного класса другим неправильным классом может менять precision/F1, не меняя accuracy или rescue/harm. Поэтому отдельно считаются такие переходы; бинарных индикаторов W/S для новых метрик недостаточно.

## Сводки и классовый анализ

Для всех условий сохраняются per-seed скалярные метрики и их средние/SD. При fit1000,20%вызовов,officialtest сохраняются TP и predicted-support для каждого класса и каждого seed, затем средние/SD class precision/recall/F1. Это средние по метрикам отдельных запусков, а не метрики одной усреднённой матрицы.

Классовые различия рассматриваются описательно. Классы с наибольшим расхождением, если приводятся, явно помечаются как выбранные после просмотра; для них не подбираются отдельные p-values.

## Заранее фиксируемая статистическая область

**Natural,fit1000,20%вызовов,officialtest**. Все 8 обучаемых методов+confidence, все36попарных сравнений. BANKING77:21пара с прежней MSE-настройкой. CLINC150:6пар с двумя критериями настройки. Всего33конфигурации.

Одна общая семья **3564контраста**:33×36×3метрики (accuracy,macro-precision,macro-F1). Остальные усреднения не дублируются как отдельные проверки, если совпадают по контрольным тождествам.

2000 paired crossed bootstrap повторов: перевыбираются общие seeds обучения и тестовые запросы **внутри каждого истинного класса**, сохраняя исходный class support. В каждом resampled пакете точно пересчитывается top-k, включая частичное включение дубликатов на границе. Все методы/критерии внутри датасета используют общие resamples; два датасета используют независимые потоки. Одна centered max-|t| поправка по всем3564контрастам. Модели, признаки, tuning и selector условно фиксированы.

Такое сравнение позволяет обсуждать обнаруженную разницу macro-метрик при необнаруженной accuracy-разнице в **одной и той же семье и процедуре**, а не сопоставлять несогласованные p-values из разных анализов. Незначимость accuracy не доказывает эквивалентность. Другие составы/квоты/размеры/clean-test остаются полностью посчитанными описательными срезами.
